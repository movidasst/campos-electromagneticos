# Simulador de Medición de Campos Electromagnéticos (CEM)

Laboratorio didáctico mobile-first de La Movida de SST Plus para practicar selección de sonda, medición de E y H/B, RMS, FFT, WPM e interpretación frente a criterios de exposición.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación valida integrantes mediante la función RPC oficial y no almacena las credenciales. Los valores y veredictos son educativos: una evaluación real requiere equipo calibrado, incertidumbre y revisión de la normativa aplicable.
